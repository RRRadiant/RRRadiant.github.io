提权

sudo -l 查看得到两个结果，一个是可以免密运行 sudo id，执行的结果是你会发现你成为了 root 用户，但是别高兴太早，这个 id 其实算是一个小坑吧。clamscan 是一个杀毒软件，我们可以利用这个进行提权。

拓展

-nr：只打印结果同时拓展正则，-n 是只打印结果，-r 拓展正则。

/No s/：指的就是 No such file or directory。

s/ //：替换命令，中间的 :.+$ 指的就是将冒号后的字符替换成空。

g：全局替换（global）。

p：打印。

最后理解，先找到 No such file or directory，然后将其替换成空，并且是全局替换，最后打印出来。

替换法。

-P：开启 Perl 兼容正则。

(?<=^).*(?=: No)：拆分成三部分。

首先 (?<=^) 指的是我要匹配的部分是从开头开始的，有了 -P 参数，就能解释为什么使用 ^，因为 ^ 在正则中代表着开头。

其次 .* 可以看作是匹配任何长度的字符。

最后 (?=: No) 指的是我要匹配的字符最右边是 : No，也就是 : No such file or directory。

-o：只显示你匹配的部分。

匹配法。

-F：指定你要找的字符，也就是 : No such。

NF>1：指的是列数大于 1。假设我们现在要对 root.txt: No such file or directory 操作，当系统找到 : No such 时，会在 : 前切一刀，这里就被分成了两列，一列是 root.txt，另一列就是 : No such file or directory，因此，如果列数大于 1，就说明成功找到并进行了切割，这个时候第一列就会记作 $1，第二列就会记作 $2。

{print $1}：最后就是打印第一列，也就是我们想要的东西。
