一、PHP 命令执行（RCE）绕过速查

在存在危险函数（如 system、passthru、exec、反引号 `）但做了正则黑名单过滤时，常见绕过思路如下：

过滤场景 绕过思路 典型 Payload
过滤常见命令关键字（如 ls、cat、flag） 反斜杠 \、单双引号拼接、通配符 */? l\s /、c\at /f*
无回显（Blind RCE） 重定向或 tee 写入 Web 目录后访问 l\s / | tee 1.txt
过滤全部字母与数字 位运算取反 ~、异或 ^、自增构造字符 (~%8C%86%8C%8B%9A%92)(~...)
禁用 system/exec 替换等价函数（如 passthru、shell_exec、反引号） printf(\l\s /`);`

二、文件包含与 PHP 伪协议整理

文件包含函数（include、require、file_get_contents 等）参数可控时，常结合以下伪协议读取源码或执行代码：

伪协议 常见用途 前置条件 / 说明
php://filter/read=convert.base64-encode/resource=... 读取 PHP 源码防止直接解析 常用于获取 flag.php 或配置文件源码
data://text/plain,<content> 传入可控字符串或 PHP 代码 需要 allow_url_include=On（用于 include）或用于 file_get_contents
file:///path/to/file 本地绝对路径任意文件读取 无视部分基于相对路径的猜测

三、防御与开发侧加固建议

  1. 严禁直接拼接用户输入到系统命令：优先使用语言内置 API 替代 system/exec；若必须调用外部命令，需使用参数化数组接口（如 Python subprocess.run([...], shell=False)）或严格的白名单正则校验（仅允许预期字符集，而非黑名单过滤）。
  2. 禁止动态文件包含：包含文件或读取路径时使用固定映射表（如 switch / 白名单字典），关闭非必要的 PHP 配置项 allow_url_include。
  3. 清理生产环境残留文件：部署前清理 .swp、.git、www.zip/www.rar 等备份与编辑器临时文件，并在 Web 服务器配置中禁止访问隐藏文件（. 开头）与压缩包。
