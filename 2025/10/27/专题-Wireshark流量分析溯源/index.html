常用 Wireshark 排查过滤语法

在应急响应与 HTTP 流量溯源中，高频使用的过滤表达式包括：

排查目标 过滤表达式 说明
定位文件上传 / 表单提交 http.request.method == "POST" 优先关注 POST 请求体中的文件名与 Payload
检索敏感目录或配置修改 http contains "etc" 快速定位对 /etc/ 下系统配置的读写操作
检索特定恶意文件后缀 http contains ".so" 或 http contains ".jsp" 排查攻击者编译或落地的恶意模块、Webshell
